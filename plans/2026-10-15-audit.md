# Audit · 2026-10-15 (main at `7042f75`)

Four read-only reviewer runs on Opus high: core and data safety; Windows platform and performance; UI, UX and keyboard; architecture, tests and process. Each one's verdict was **fix first**.

Measured: all 2232 tests pass, line coverage meets every floor (core 98.4 %, fs 95.3 %, store 93.5 %, diag 96.6 %, ui 94.9 %, xtask 91.7 %), `cargo deny` is clean, and CI on `main` is green. The problems are not in what is tested. They are in what is missing, and in promises the docs make that the code does not keep.

Each finding notes whether the reviewer verified it in code (V) or suspects it and it needs a Windows run (S).

## Critical and High

### Data safety

1. **Start-up recovery silently rolls back interrupted jobs and deletes copied files matched by path only** (V).
   - Where: `rusty-app/src/jobs/mod.rs:127-160`, `gui.rs:82-84`, `rusty-fs/src/job/undo.rs:32-38`.
   - Jobs stay `running` after a crash, a job panic (`work.rs:101` never calls `finish`), a failed `finish` write, or the 10 s close timeout.
   - Fix: ask the user (Resume, Roll back, Leave); record size, mtime and file ID per created target, and remove only targets that still match; run recovery off the UI thread.
2. **A cross-volume move deletes sources at the end without re-checking them** (V).
   - Where: `op_plan/mod.rs:155-158`, `job/run.rs:130`.
   - A source saved during a 20-minute move is deleted while the target keeps the old copy.
   - Fix: compare size, mtime and file ID before each `RemoveFile`, or interleave copy, verify and delete per file.
3. **Closing the window cancels running jobs without asking and blocks the UI up to 10 s** (V).
   - Where: `window_view/mod.rs:223-230`, `browser/operate/mod.rs:94-107`.
   - Fix: a confirm (Wait / Cancel and quit); never sleep on the UI thread.
4. **App-level file I/O skips the verbatim path** (V).
   - Where: `rusty-app/src/files/mod.rs:26-32`, `launch/mod.rs:23`, `editor/mod.rs:118`.
   - F3 on `report.` shows `report`, and Ctrl+S overwrites `report`. Names with unpaired surrogates are "not found".
   - Fix: use `rusty_fs`'s OS path conversion everywhere; run the hostile-name corpus through `FileHooks` on Windows CI.

### Never block, never hang

5. **The I/O queue is never configured, and stale listings are never cancelled** (V).
   - `set_volume` has no caller, so every volume is `Unknown` with a limit of 1. Listings, plans and renames share one owner.
   - One dead SMB listing stalls every later listing, rename and plan on that volume, in both panes.
   - Fix: map `DriveKind` to `VolumeKind` on drive refresh; one owner per tab, cancelling the previous request; separate lanes for listings and mutations.
6. **The viewer and editor do file I/O on the UI thread** (V).
   - F3 `pick` and `read` (up to 16 MB), Ctrl+S `write` with fsync, paged reads inside `draw`, and the PATH scan in `editor.remember`.
   - Fix: run them through `background_spawn` with a timeout; draw paged rows from a cache filled in the background.

### Architecture (blocks modularity, the palette and keymaps)

7. **The command system covers only navigation, selection and layout** (V).
   - Copy, move, delete, rename, sort, filter, F3/F4, drives and path edit are `FileListAction`s or direct `Browser` calls, with keys hard-coded in `file_list/keys.rs:48-90`.
   - The Ctrl+K palette, TOML keymaps, the TC keymap, record/replay and plugins have nothing to call.
   - Fix: a `Command` per action with parse and print; one dispatcher; keybindings as data.
8. **The runtime lives in `rusty-ui`** (V).
   - `Browser` owns `AppState`, the I/O queues and jobs; sort and filter state sit in UI `HashMap`s (not saved, not replayable). `rusty-app` imports `rusty_ui::browser`.
   - Fix: a `rusty-runtime` crate; the UI gets a read-only view and a dispatcher; sort and filter move into core.
9. **`FerriteWindow` is a god object with no module seed** (V).
   - It has 18 fields and about 2,000 lines of `impl` spread over 12 files. `StartOptions` gains a hook bundle per feature. There is no `Module` trait, registry or cargo features.
   - Fix: define `Module` (id, commands, bindings, settings schema, slots) and a registry; port the viewer, editor and drives first.
10. **Diagnostics are not wired** (V). There is no tracing subscriber, no `LogLayer`, no panic hook and no crash report, and `diag-report` passes empty registries. D20 is marked done.

### UX gaps a user meets on day one

11. **Advertised controls are dead** (V).
    - F9 Drawer, F10 Palette, Ctrl+K and the title-bar search do nothing.
    - F-key cells cannot be clicked.
12. **Tabs cannot be opened or closed** (V). There is no Ctrl+T, Ctrl+W, Ctrl+Tab, + or ×.
13. **Running jobs cannot be cancelled from the keyboard** (V).
14. **Planning shows nothing and can confirm a stale plan** (V).
    - F8 on A, then on B, can pop A's dialog with Confirm focused.
    - There is no debounce, despite `architecture.md:218`.
15. **There is no refresh and no watcher** (V): no Ctrl+R, and files created by other apps never appear.

### Process

16. **Push CI gates little** (V).
    - fmt, typos, taplo, size, deny and audit run only in the manual Linux job.
    - `build-windows` has no `needs:`, so an exe is uploaded even when tests fail.
    - Windows-only code is outside coverage.

## Medium

- **Recycle** goes through the `trash` crate (S). Trailing-dot names may hit the wrong file, and shares without a Recycle Bin may delete permanently with no plan warning. Fix: `IFileOperation` directly; mark network targets as permanent in the plan.
- **No re-check at execution** (V), contradicting `architecture.md:215`.
  - A subfolder swapped for a junction after scanning is acted on through the junction.
  - Rename is check-then-`rename` with `REPLACE_EXISTING`. Fix: `MoveFileExW` without replace.
- **Copies lose metadata** (V): hidden and system attributes, ADS including `Zone.Identifier` (Mark-of-the-Web), creation time. Fix: `CopyFile2`.
- **No single instance** (V). Two instances overwrite each other's session and contend for `ferrite.db`.
- **Every operation does a full recursive scan** (V), even recycle and same-volume move; one unreadable child aborts the operation.
- **The session file can outgrow its 8 MB reader limit** with many tabs. Rows are saved for every tab.
- **The listing pipeline does not stream** (V/S): it sorts twice (once on the UI thread) and keeps two copies of every name. Per-tab caches leak when a tab closes.
- **Shutdown can hang** (S): `IoQueue::drop` joins workers stuck on dead shares.
- **Folder measuring is never cancelled** (V), and each result copies the details array on the UI thread.
- **Launching uses `explorer.exe`**, not `ShellExecuteExW` (V): no Mark-of-the-Web prompt, comma names may fail, and an `explorer.exe` planted next to the portable exe could run.
- **Listing follows link targets** (V): one SMB timeout per link to a dead share.
- **The protected-location confirm asks to type DELETE for copy and move**, and Enter in the field does nothing.
- **F3 is an editor, not a viewer**: Lister habits edit the file; F3 closes instead of finding next; Alt+1/Alt+3 will shadow the Beta workspaces (Alt+1…9).
- **Space cannot go into the quick filter.** The waiting view traps Tab and Backspace.
- **Hint text in `faint` fails 4.5:1 contrast**, and the contrast test skips it. There is no high-contrast theme.
- **The job strip has no height cap**, and failed rows are dropped before the user reads them.
- **A folder-size error shows "0 B".**
- **Mouse parity**: no long-press native menu, no right-drag range, Ctrl-click or Shift-click.
- **The UI draws only two panes** and ignores the core layout tree.
- **Command errors are discarded** with `let _`.
- **Settings have no schema and are mostly not applied** (the mode is hard-coded to Light).
- **There are no Fluent files.**
- **There is no release workflow, signing, version policy or app manifest** (`longPathAware`).
- **Start-up recovery runs before the first frame.** Removable drives are probed every 2 s with no `SetErrorMode`.

## Low

- The UI does O(n) status and selection work on every render.
- A successful reconnect steals focus.
- `lands_inside` is case-sensitive.
- `volume_of` is `/` for every Linux path.
- `integrity_check` never runs, and the journal silently turns off if its database fails to open.
- Recovery cost grows quadratically.
- The vendored GPUI patch can vanish on a gpui-kit bump.
- Empty crates (`rusty-cache`, `rusty-index`, `rusty-plugins`, `rusty-term`).
- Docs drift: D30 Linux CI, `plans/README.md` "P2 is running", the 30 MB target, `architecture.md` "proposal".
- `.gitignore` has `/target/` only, so `spikes/*/target/` would be committed by a blind add.

## Solid

- The core is pure and deeply tested: proptests, snapshots, replay.
- Lints are strict, and the toolchain and actions are pinned by SHA.
- Temp-file copy with `create_new`, `sync_all`, a size check and rename.
- Links are never descended; non-recursive folder removal.
- The session file has magic, CRC and `.bak` recovery.
- Verbatim paths in `LocalFs`; the WNet FFI is correct.
- The drive probe has a timeout and a claim set.
- `PagedFile` is bounded; the line index is cancellable.
- The Esc order is scoped and tested; Shift+Del focuses Cancel; the list is virtualised (100k rows).

## Proposed order

1. **P15 Safety** (data loss first): items 1, 2, 3 and 4, recycle via `IFileOperation`, re-check before destructive steps, no-replace rename, `CopyFile2`, single instance.
2. **P16 Never block**: items 5 and 6, listing lanes and cancel, a streaming listing, measuring cancel, shutdown without joins, recovery off the UI thread.
3. **P17 Commands and runtime**: items 7 and 8; every action becomes a command; keymaps as data; a `rusty-runtime` crate; sort and filter in core. This unlocks Ctrl+K and the TOML keymap.
4. **P18 Modules and settings**: item 9 and the settings schema; port the viewer, editor and drives; wire diagnostics (item 10).
5. **Alongside, small**:
   - CI: lint, deny and audit on push; `needs:` on the exe build.
   - Day-one UX: tabs (Ctrl+T/W), Ctrl+R, job cancel key, F-key bar truth, plan feedback and staleness.
   - `.gitignore`, docs drift, contrast.
