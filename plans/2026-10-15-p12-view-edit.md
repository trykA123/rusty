# P12 · F3 viewer and F4 editor

## Goal

Owner request (2026-10-15): F3 views files in a built-in viewer where you can search, replace and type; F4 edits in a program the owner picks (VS Code, vim, Notepad++, any `.exe`).

## Decisions

- **F4:** the first F4 asks for the program, suggesting VS Code, Notepad++ or Notepad when found; the program must exist or be on PATH; the choice is saved as `[editor] path` in `ferrite.toml`; later F4 opens the file directly; Shift+F4 asks again. Folders are skipped.
- **F3:** gpui-kit's code editor fills the window above the F-key bar: line numbers, tree-sitter highlighting by extension (34 grammars; SQL is out because its grammar pins an old `cc` that conflicts with `embed-resource`), Ctrl+F find and replace, typing, Ctrl+S saves atomically and keeps CRLF line endings. Esc or F3 closes; with unsaved changes the first Esc warns and the second discards. Files over 16 MB and binary files (a NUL byte in the first 8 KB) are refused with a pointer to F4; text that is not valid UTF-8 opens read-only.
- D37: the `.exe` size limit rises to 60 MB.
