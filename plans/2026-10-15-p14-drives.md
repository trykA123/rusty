# P14 · Drive bar, network drives and typed paths

Status: running · Repo: `<repo>` · Branch: `p14-drives` · Started: 2026-10-15

## Goal

The owner can switch drives the Total Commander way. A drive bar sits above each pane, and Alt+F1 / Alt+F2 open a drive menu. Mapped network drives are marked, and disconnected ones reconnect on click. Any path can be typed with Ctrl+L, including UNC paths. A network folder that does not answer never freezes the pane (D19).

## Decisions

- D1 — **Drive bar per pane**, above the path bar.
  - Each drive is one button: letter plus a Lucide icon by kind (hard-drive, usb, network, disc, memory).
  - The current drive is accented. Disconnected network drives are dimmed.
  - A thin usage bar under each button shows how full the drive is (better than TC). The tooltip shows label, kind, and free of total.
- D2 — **Where a drive click goes.**
  - On the current drive: the drive root.
  - On another drive: the last folder visited on that drive in this tab (newest first: back history, then forward history), otherwise the root. Like TC, but per tab and from the persisted history, so it survives restarts with no format change.
  - This is the core command `pane.go-drive root=<root>`.
- D3 — **Drive menu.** Alt+F1 opens the drive menu for the left/first pane; Alt+F2 for the right/second pane (TC keys).
  - Rows show letter, label, kind and a free-space bar. Typing a letter jumps to that drive; Enter opens; Esc closes.
- D4 — **Enumeration in `rusty-shell`.**
  - Windows: `GetLogicalDrives` and `GetDriveTypeW`. Mapped drives resolve to UNC with `WNetGetConnectionW`. Remembered but disconnected drives come from `WNetOpenEnumW(RESOURCE_REMEMBERED)`.
  - Labels and space (`GetVolumeInformationW`, `GetDiskFreeSpaceExW`) are read per drive on a background thread with a 2 s timeout; no answer means no label and no space, never a wait.
  - Linux: `/` plus mounts under `/mnt`, `/media` and `/run/media/<user>` from `/proc/self/mounts`.
  - The pure assembly (`assemble`, `parse_mounts`) is tested everywhere. The Windows calls get a smoke test on Windows CI.
- D5 — **Refresh by polling, off the UI thread.** The drive mask is checked every 2 s (cheap); remembered network drives every 30 s. Details are re-read only for drives that changed. No `WM_DEVICECHANGE` hook (GPUI owns the window procedure).
- D6 — **Reconnect.** Clicking a disconnected drive calls `WNetAddConnection2W` with `CONNECT_INTERACTIVE` in the background, so Windows asks for credentials when needed. On success the pane opens the drive; on failure the pane shows the message.
- D7 — **Typed paths.** Ctrl+L, or a click on the path bar's empty space, turns the path bar into an input with the current path selected.
  - `typed_location` (pure, core) accepts absolute paths, UNC `\\server\share`, forward slashes, `%VAR%` and `~` expansion, `.` and `..`, and paths relative to the current folder. It trims quotes from "Copy as path".
  - If the result is a file, the pane opens its folder with the cursor on the file (better than TC). If it does not exist, the error shows inline and the input stays open.
  - Esc cancels.
- D8 — **Waiting state.** A listing still pending after 2 s shows "Waiting for <path>… Esc goes back" in the pane. Esc drops the request and returns to the previous folder. The listing job keeps its own I/O queue and timeout.
