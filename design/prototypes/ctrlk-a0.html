Ctrl+K command center (P40 A0)

State

The box works: type to filter, ↑/↓ move, Tab next group (path mode: complete), Enter run or open, Shift/Ctrl/Alt+Enter reveal, other pane, new tab, Ctrl+Shift+C copy path, Esc clear then close, Ctrl+K toggle. Keys 1–4 switch direction when the input is not focused; Alt+1–4 always.
