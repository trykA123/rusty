Ferrite roadmap

Where we are, in features you can try. Updated 19 October 2026.

Where we are

1 · Works today in the alpha download
  • Two panes with tabsBack and forward. Your session comes back at start.
  • Fast file listHuge folders, filter as you type, sizes in KB to TB, sort by name, extension, date or size.
  • Total Commander style selectionSpace, Insert, right-click, Num+, Num− and Num*.
  • Drive bar and network drives
  • File operationsCopy, move, rename (F2), new folder, Recycle Bin and Shift+Del.
  • Background jobsProgress and cancel. A job cut short is rolled back safely at the next start.
  • F3 viewer for textColours for many languages, hex view, huge files page by page, correct encodings.
  • F4 editor
  • New today: images in F3Zoom, pan, next and previous image, correct rotation.
  • New today: search and marksSearch shows “3 of 1,248”. Find All, colour marks (Ctrl+1 to 8), bookmarks, Follow for growing logs. All kept after restart.
  • Archives in F3Zip, 7z and tar listed with sizes and dates. Filter, and Enter opens an entry.
  • Fonts in F3Sample text in several sizes and a glyph grid.
  • Images: own keys and mouse zoomF3 images show their own keys in the bottom bar. The mouse wheel zooms around the pointer, and drag pans.
  • Live search countThe “x of y” count updates while you type.
  • Stepping through filesSpace and Backspace step files only for images. A held Backspace no longer freezes.
  • Light and dark themesThey follow Windows. F-key bar at the bottom.
  • New today: the new look, first partThe panes are cards on a Mica background. A “Ferrite ▾” app button, a centred search and one drive pill with a dropdown. The F-key bar is now keycaps that switch layers while you hold Shift, Ctrl or Alt. In test build alpha-2026-10-16e.
  • New today: faster foldersFolders are listed with native Windows calls. Folders you visited come back at once and refresh in the background. The network share is now very fast.
  • New today: Markdown in F3Ferrite draws it itself: headings, lists, tasks, quotes, tables, code and links. Huge or odd files open as plain text.
  • New today: JSON, YAML and XML as a treeAlt+←/→ folds a branch. Ctrl+Shift+←/→ folds all. Ctrl+1–9 shows the tree to that depth.
  • New today: Windows “Send to” menuIt no longer blocks the window. This is groundwork for the context menu.
  • New today: context menuHold right-click for about 0.4 s, or press the Menu key or Shift+F10. Ferrite’s own actions come first, then the Windows items (Open with, 7-Zip, Send to). Type to filter. It opens in one piece with a short motion. In test builds alpha-2026-10-16g and 16h.
  • New today: app menu on F10Quick tiles for Theme, Density and Hidden files.
  • New today: tab shortcutsCtrl+Tab, Ctrl+PageUp/Down, Ctrl+1 to 9 and Ctrl+W.
  • New today: panes back to the middleDouble-click the divider or press Ctrl+Shift+0.
  • New today: compact F-key barFull labels in less space, and a thinner ring around the active pane.
  • New today: folders refresh by themselvesNew, deleted and renamed files appear on their own, for example after “Extract here”. Ctrl+R refreshes by hand.
  • New today: copy cardA card with progress, speed and time left. Ctrl+J shrinks it into a pill next to F10.
  • New today: pause and resumePause and Resume for copies, moves and deletes. A paused copy never leaves a half file under the final name.
  • New today: context menu in the viewerThe F3/F4 menu fits the file kind: text, Markdown, JSON/YAML tree, table, image, archive and hex. It has copy, find, go to, fold and “view as”, plus Copy path:line, Copy value, Copy key, Copy column, Copy link and Copy image.
  • New today: keyboard focus in dialogsIn confirm and rename dialogs, Tab and the arrows move between buttons. Delete dialogs start on Cancel.
  • Folder preview side sheetIt opens over the other pane. A folder shows its structure first, then stats, types and the largest files. F3 on a folder is the one way in, and Esc closes it. The Ctrl+Q shortcut and the preview button are gone.
  • New today: diagnostics logA redacted log with no paths or file names, for bug reports.
  • In the next download: safer context menusThe Windows menu refuses names Windows would rewrite. Right-click in the viewer acts on the clicked row. Retry reloads a failed Windows submenu. Linux shows only the actions that work.
  • In the next download: instant panes at startPanes draw at once from a disk cache of the open tabs’ folders, then refresh.
  • Delete and Recycle dialogsEnter and Space press the focused button.
  • Settings file is safe to editYou can edit or even delete ferrite.toml while Ferrite runs. An interrupted save is recovered, and comments at the end of the file stay in place.
  • Start-up options--left and --right open the panes in given folders. --profile runs with separate settings. --metrics measures start-up.
  • Start-up time and memory are measuredEvery build is measured. Memory is about 67 MB, under the 80 MB target. Warm start is about 180 ms on the build machine, which has no graphics card, so the real number comes from your PC. Tuning on real PCs is parked until the alpha features are in.
  • In the next download: Explorer clipboardCtrl+C or Ctrl+X in Ferrite, then paste in Explorer, and the other way round. Ctrl+V pastes straight into the active pane.
  • In the next download: files in useA file that is in use names the program that holds it, for example “in use by Microsoft Word”.
  • In the next download: shortcut searchSearch finds a key typed in any form: “ctrl+f5”, “F5 ctrl” or “Ctrl - F5”.
  • In the next download: window backgroundMica on Windows 11 22H2 and later. An opaque window with a gradient on Windows 10 and Windows 11 21H2.
  • New today: one Ferrite at a timeOnly one Ferrite runs. ferrite <path>, or opening a folder from outside, opens it in the running window.
  • New today: shortcut drawerHold Ctrl, Shift or Alt for a moment and a drawer above the F-key bar shows every shortcut on that layer, grouped. You can turn it off or show F-keys only.
  • New today: crash reportAfter a crash or a hard kill, the next start says “Ferrite closed unexpectedly last time”. Save report writes a zip to Downloads with the diagnostic report and a redacted crash record. Dismiss closes it. Nothing is sent anywhere.
  • In the next download: folder prefetchRest the cursor on a folder for a moment and its listing loads in the background, so Enter shows it at once. It works on network shares too and never slows the open folder.
  • New today: window opens where it wasPosition and size are kept per monitor setup, for example laptop alone or docked. The window always opens on a visible screen.
  • In the next download: sharp at any display scaleFerrite already draws sharp at any scale, because the UI toolkit handles per-monitor DPI. The diagnostic report now says so.
  • In the next download: drive kindFerrite knows if a drive is an SSD, a hard disk or a network share. This is groundwork for the faster copy.
  • New today: settings side sheet (Ctrl+,)Changes apply live and Ctrl+Z undoes them. Each row shows its TOML key, and F3 jumps to it. Saving keeps your comments in the settings file.
  • New today: Default or Changed on every settingEach row says if the value is the default or your own, with Reset. A footer counts “N changed”, and a Live chip marks live settings.
  • New today: browse folders in the previewEnter goes into a folder and Backspace goes up, with a breadcrumb. Shift+Enter opens it in the pane. Arrows open folders as a tree. Space marks a folder and counts its size.
  • New today: Auto copyCopying uses the Windows copy engine, which keeps attributes and streams and copies on the server for shares. Several files copy at once where the drives allow. Overwrite replaces the old file in one step, so a crash never leaves a half file.
  • Markdown live preview while editingSplit view with Ctrl+Shift+V. Wide tables scroll sideways instead of squeezing columns.
  • Offline state for network sharesThe last listing stays visible marked “Offline”, and retries run in the background.
  • Automotive: Intel HEX and S-record memory viewA ranges drawer, an inspector and go to address. Gaps are folded. Shipped in test builds alpha-2026-10-19g to 19i.
  • Automotive: ELF symbol viewA sections and segments navigator, and a symbol inspector with the source file and line from the debug info. It shows flash and RAM totals, readable C++ and Rust names, filters as you type, and Ctrl+G jumps to an address.
  • Automotive: CAN trace view for Vector ASCAn IDs drawer and a frame inspector. It follows a growing log.
  • PDF viewer in F3Zoom, find with a hit list, a pages and outline drawer, password-protected files and a calm preview. It runs on the PDF engine in a separate helper process.
  • View menu (Alt+V) in the viewersSimple, Rich or Custom, with a toggle for each part. Ctrl+B and Ctrl+I open the left and right drawers the same way in every viewer. A Display page in settings sets the defaults.
  • Crash reports with file and lineThe saved report now shows real function names with the source file and line.
2 · Being finished now
  • Right-click on empty spaceA folder menu with New file (Shift+F7) and the Windows background menu. Done and waiting for Windows CI.
  • Cache sizes in diagnosticsThe diagnostic report shows how much disk each cache uses, backed by a long stress test. In progress.
  • Steadier Windows CIFixes for tests that fail now and then. In progress.
  • Automotive: TASKING linker map readerThe reading part is done. The map screen is next, and it will be checked on a real map file.
  • Undo of an overwriteUndo brings the old file back with its bytes and attributes. Under review for data safety.
3 · Comes next for the alpha
  • Automotive: linker map screenThe screen for the TASKING map reader: flash use per object.
  • View parts in the main windowThe same Simple, Rich and Custom toggles for the panes, tabs and bars.
  • Automotive: more filesDBC and A2L signals, ARXML, MDF4 measurements, and TRC and BLF CAN traces.
  • Auto copy: setting and benchmarkAn Auto or Standard choice in settings. A benchmark against robocopy and Explorer.
  • Translation-ready textEvery text in the app moves into translation files. English only for now.
  • More colours and encodingsColours for m4, OIL, DCM and Notepad++ user languages. An encoding picker.
  • Spreadsheets in F3Excel and other spreadsheets (xlsx, xls, ods) as a table.
  • Viewer chromeSymbol list, bookmarks and a coloured scrollbar strip.
  • Defaults and settings searchA notice when Ferrite’s defaults change after an update, with “Keep old value”. A “Find a setting” field.
  • Every shortcut changeableEvery action can be rebound. A keymap.toml file, plus a shortcuts page in settings.
  • Known bug: Follow on WindowsFollow (Alt+F) does not show new lines yet on Windows. Parked for now.
