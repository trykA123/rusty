Coming in 21d not in the 21c download

Ctrl+K finds files anywhere

  • Ctrl+K searches a disk index, not just the open folders. By default it indexes your user folder.
  • Settings › Search chooses the index mode (Auto, Service, Walk, Off), the drives, skipped names, and network and removable drives. These rows now apply.
  • While the index builds, the box and the activity strip show “Indexing C: · 12,345 files”.
  • A dead network share blocks only itself; local drives answer at once.

Keys

  • F4 on a folder opens it in your editor.
  • F9 copies the full path of the file under the cursor, or of every marked file.

Windows index service (optional)

  • Settings › Search shows whether the service runs, with Install and Remove. Windows asks for admin rights; cancelling changes nothing.
  • The service keeps a whole-disk index of NTFS drives, so a new file shows up in a second.
  • Safety: only your account can ask it; an untrusted install folder is replaced, never reused; a failed reinstall puts the old version back; a stuck client or a damaged index file cannot stop it.

Before 21d ships

  • Done: two security reviews of the search part, and their fixes.
  • Your check on the work PC: install the service, find a file created a second ago, remove it.

Comes after

  • Rich ELF and MAP: the remaining address texts and View-menu rows.
  • Multi-rename: undo history and log.

New in 21c in the 21c download

Ctrl+K

  • Enter opens a hit. Shift+Enter shows it in its folder. Ctrl+Enter opens it in the other pane. Alt+Enter opens a new tab. Ctrl+Shift+C copies its path.
  • “Go to folder…”, “Open folder in new tab…”, “Mark by pattern…” and “Unmark by pattern…” ask for their value in the box. Tab completes folders.
  • Enter typed quickly runs the best result, not the first command shown.
  • Esc clears the text first.
  • A slow network path shows “Checking…” instead of hanging.

Multi-rename

  • Ctrl+Z puts a whole rename batch back.
  • The preview highlights what changes in each name and what Find matched.
  • A path over 260 characters gets a warning.

TASKING memory definition files

  • .mdf files open as a table of chips, spaces and addresses.

Rich ELF and MAP views

  • The “who uses the flash” map colours each group, and the files inside in shades of it.
  • Every tile shows size and share. Its area matches its real size, with “N more” for the rest.
  • Usage bars never show 100% while space is free. Reserved space has its own hatched part. The inspector shows exact bytes.
  • Keys for the address strip and the map.

MAP view

  • The status line says which parts of the map were not read.
  • The Size column is hidden when the map has no sizes.

Search index (Windows)

  • A background service keeps a whole-disk index and answers searches. Built, not connected to Ctrl+K yet.

Also in 21c

  • Ctrl+K: a dead network folder no longer piles up work in the background.
  • Rich ELF and MAP: focus and Esc fixes, and zoom kept when regrouping.
  • Settings: a Search page.
