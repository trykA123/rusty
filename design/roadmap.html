Rusty roadmap

Ship a small, stable and fast v1 first. A core that is always on, and every other feature as a module you can turn off. New capabilities arrive as modules, never as weight on the core.

≤ 400 msCold start to first usable frame
≤ 150 msWarm start
≤ 50 msSummon from tray (v1.2)
< 80 MBRAM, two panes, idle
< 30 MBOne portable .exe
  • Never lose a fileRecycle Bin by default, plan before acting, undo, crash-safe journals.
  • Feel instantFirst frame from cache, virtual lists, work only for what is visible.
  • Stay lightLazy start for everything optional. Every cache and queue has a budget.
  • ModularSmall core. Features are modules; themes and keymaps are packages.
