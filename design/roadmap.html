Alpha: built, checks open

Four focus areas. All four are built; owner checks and daily use remain.

BuiltSign-off open

All four features are in the pre-release alpha-2026-10-26. Status labels replace the old percentages, which mixed building with release checks.

Now in progress on branches

  • Rename to Navo. New name and a new n_ icon. Your profile (settings, tabs, history) moves once, safely, with crash recovery. The old Ferrite folder is then renamed to "Ferrite.migrated-to-navo". The installed index service is upgraded from a one-time notice. Done: profile folder and temporary-file names. The move engine is built and in its review-fix round. To do: app start order, instance names, index service, program name, on-screen text, icons, CI and docs. This page says Ferrite until the rename lands.
  • Start-up splash. A small native Windows window with the n_ icon and the "navo" wordmark. It appears only when start-up takes longer than 200 ms. Not on Linux.

 

  • New right-click menu. The real Windows shell menu in Ferrite's style. Filter at the top. Submenus open in place, with a back row. Full classic menu; Shift adds extended items. The classic Windows menu opens if anything fails. Two builds are made side by side to compare quality.
  • Fonts. Space Grotesk for the brand, Inter for the interface, JetBrains Mono for paths and viewers. Decided. Not built yet.

After the backend merge

  • The delete safety net (1 to 7 days retention) has its own branch. Retention engine, recovery, quarantine and crash-safe temporary-file cleanup are built and reviewed. All of it is behind an experimental launch flag, so normal use does not change. The branch is being moved onto the current main.
  • After the merge the engine is in the app but still off by default.
  • Still missing for users: turning it on in delete and overwrite jobs, settings, a "Recently deleted" view, and general undo.
  • A faster lookup for very large retention catalogs is parked.

Merged since the release on main

  • Six built-in colour themes: Open sea (default), Red bill, Black cap, Fine mesh, Grain, and Ink and amber. Each has a light and a dark form. Pick one in Settings > Appearance > Colour theme. It applies at once.

In the alpha-2026-10-26 release

  • Drag to and from Explorer, right-button drop choices, auto-scroll near list edges, and hover-open for folders, tabs and drives.
  • Journaled rename with safe undo and crash recovery. Rename works on FAT and exFAT drives; undo there checks size and time.
  • Edited, imported and pasted rename lists, sorting, counters and an optional rename log.
  • Rich ELF/MAP views find the memory companion and apply module prefixes live.

Verification

  • Windows CI is green: 7,118 tests passed.
  • Linux passed all 10 gate steps.

Next before alpha sign-off

  • Owner checks on the work PC: Explorer drag, the index service, and rename on a FAT or exFAT USB stick.
  • Two weeks of daily use with no lost or damaged files.
  1. 1

    Multi-select and drag and drop

    ●Built; Explorer check open

    Marking, lasso, and drops on panes, folders, tabs, path crumbs and drives work. Alt-drop makes shortcuts. Drag to and from Explorer works, with right-button drop choices. Lists scroll near their edges while you drag. Folders, tabs and drives open on hover. Linux external drops are Copy-only.

  2. 2

    Rich ELF and MAP views

    ●Built; final review open

    Rich views show memory use, address strips, treemaps and tables. Companion discovery finds an unambiguous memory definition or MAP file. Configured module prefixes apply live. Final review and work-PC checks remain.

  3. 3

    Ctrl+K command center

    ●Built; owner check open

    Commands, recent files, tabs, folder search, typed paths and the disk index work. Search settings and the optional Windows index service work. The index service still needs an owner check on the work PC.

  4. 4

    Multi-rename (Ctrl+M)

    ●Built; USB check open

    Renames are journaled, with safe undo and crash recovery. Edit, load, paste or copy names; move or sort preview rows; restart counters per folder. An optional log records finished batches. Rename works on FAT and exFAT drives; undo there checks size and time. Needs an owner check on a USB stick.

  • DBC and A2L viewer in F3Signals, messages and parameters as a table you can search. The file readers are done.

  • Viewer chrome and pinsSymbol list, bookmarks and a coloured scrollbar strip, and pins.
  • Context menu: the Windows menu in Ferrite’s styleThe same items as Explorer, with the search field at the top. Submenus open in place.
  • Clone a tab into the other paneCtrl+Shift+Up opens the current folder as a new tab in the other pane.
  • Cache sizes in diagnosticsHow much disk each cache uses, with a long stress test.
  • Steadier Windows testsFixes for tests that fail now and then.
  • Follow on Windows (Alt+F)Known bug: new lines do not show yet. Moved out of the alpha.
  • Windows installer (NSIS)Installs over the old version, with Start-menu and uninstall entries. Unsigned at first; the portable zip stays.
  • Rich map, deeperA picked tile keeps its colour with a border, and the map opens on one module, so its files fill the space.
  • WorkspacesSaved sets of panes and tabs.
  • Undo for every jobFrom the UI. The job journal is already built.
  • More copy modesVerify and a speed limit. Parallel copy is already in.
  • Custom themesYour own colours. The settings window with search and live apply is already in.
  • Spreadsheets in F3Excel and other spreadsheets as a table.
  • Every shortcut changeableA keymap file and a shortcuts page.
  • Layout that fits any window sizeColumns stay under their headers, long names end in “…”, less important columns hide on narrow windows, one pane when very narrow, and tabs that fit. Checked by automatic tests at several widths.
  • More panes, tiledMore than two panes, split and arranged like a tiling window manager (Hyprland), all from the keyboard. Design comes first.
  • AccessibilityFull keyboard use, high contrast, UI scale.
  • Open a terminal hereCopy path (F9) and folder search (Ctrl+K) are already in.
  • Done notificationsWindows alert when a long job ends.
  • Network refresh modesWatch, interval or manual.
