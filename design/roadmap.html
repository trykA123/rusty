The four alpha features

All four are in every pre-release since alpha-2026-10-26, and you checked them on a Windows PC. Chips show status instead of percentages, because the old percentages mixed building with release checks.

  • BuiltChecked

    Multi-select and drag and drop

    Mark files, then drag them between panes, folders, tabs, path crumbs, drives and Windows Explorer.

  • BuiltChecked

    Rich ELF and MAP

    See where memory goes in firmware files, with address strips, treemaps and tables.

  • BuiltChecked

    Ctrl+K command center

    One box for commands, recent files, tabs, folders, typed paths and a disk index, with an optional Windows index service.

  • BuiltChecked

    Multi-rename (Ctrl+M)

    Rename many files at once with safe undo, crash recovery, and optional log.

Beta (v0.9): fast search, workspaces, tiled panes, safe deletes8 items, 4 priority, 6 done earlier

The owner reordered the beta on 27 October 2026 (D85). Built in this order.

  • coreSearch index like Everything (D83)mostly donepriorityCtrl+K answers at once from the Navo Index service, even while it updates. Navo does not walk folders on NTFS drives. The service starts from its saved index and uses less memory. A benchmark next to Everything comes last. The busy-answer fix is done.
  • coreDelete safety net (D65)next releaseShift+Del and overwrites keep the old files for 1 to 7 days. A “Recently deleted” view shows them, and Ctrl+Z restores them. Merged, coming in the next release.
  • coreWorkspaces (Alt+1…9) with the trayin progresspriorityNamed workspaces, drafts, Save and Discard, shown in a tray (D82). The model, the commands and the session file are done.
  • coreMore than two panes, tiled like Hyprland (D80)in progresspriorityPresets on Ctrl+L. Split, move, resize, swap and close from the keyboard. Save your own presets. Tile notation, pane operations and applying a layout are done.
  • coreFind files by content and attributesin progressprioritySearch in Ctrl+K. Results open as a tab you can work in. Virtual collections hold saved searches, snapshots and files you pick by hand. The query, the content matcher and the collection store are done.
  • moduleClipboard history and notesplannedAlso the summon hotkey and tray, which open in 50 ms or less.
  • coreBackground work that never waitsmostly doneJob pools with priorities. Folder sizes stop when you leave the folder. Size on disk. Hard links are counted once.
  • coreAccessibility basicsmostly doneNarrator reads lists, dialogs and Ctrl+K. Focus is visible everywhere. Reduced motion, contrast themes and UI scale.

v1.0: replaces Total Commander5 items

For daily work (D39). Features that Total Commander has are built to beat it, not to copy it.

  • coreCompare and sync (D40)Folder compare in the panes. A calm full-window look with a change map on each scroller (chosen). Sync as a plan with undo. Cached BLAKE3 hashes, syntax-aware text diff, paged diff for huge and binary files, and image compare. Engine in the shared compare crate.
  • infraSigned portable .exe and installer (D73)The installer’s uninstaller also removes the index service. User guide, soak test and steadier Windows tests.
  • coreDefault file managerOptional: Win+E opens Navo.
  • coreInspector column and archives as foldersPreview and properties, thumbnails, and zip, 7z and tar with gz, xz and zst as folders. File details, owner and hashes are done.
  • coreModule registry and settingsTurn modules on and off while running, with safe mode. The settings window is generated from module schemas. Notifications for long operations.

Exit: every target is met on a clean Windows 11 machine, and a week of work runs without opening Total Commander.

Also targeted: summon from the tray in 50 ms or less (beta). The portable .exe has no size limit (D44); the CI guard is 160 MiB. On the CI runner, which draws in software, warm start to first frame is about 180 ms and idle memory about 67 MB, so most of the gap is on real hardware: the time before the program starts and GPUI’s start-up on a real GPU.
