navo

What Navo can do today, and what comes next.

A keyboard-first file manager for Windows, built to replace Total Commander.

What you can use today.

Find & navigate

  • Ctrl+K command center

    One box for commands, recent files and folders, open tabs and paths. It ranks the commands you use most. Tab switches between Names, Content, Commands and Collections.

    coreAlpha

  • Disk index

    Finds files anywhere on your drives at once, even while the index updates. The optional Navo Index service watches NTFS drives, so new files show up within a second.

    coreAlpha

  • Search inside files

    Content mode in Ctrl+K reads the text of your files. Hits show as “line · file:line” and Enter opens the file at that line. Alt+C and Alt+R switch case and regex.

    coreBeta

  • Results tab

    Search results open as a tab you can work in. Copy or move from it with F5 and F6, and keep the folder structure if you want. Your query is the tab name, with progress while it searches and hit counts in the status bar. Files you move or delete leave the list, and dragging files out works.

    coreBeta

  • Two panes with tabs

    Tabs, history and session restore take you back to where you were. A drive bar covers network drives, with an offline state for shares that go away.

    coreAlpha

  • Fast folders

    Smooth lists for large folders. Folders refresh by themselves and the next folder is prefetched.

    coreAlpha

  • Quick filter finds anywhere

    Type to filter: 4999 finds file-4999, the matched part is highlighted and the cursor lands on the best name. ^ keeps names that start with the text; * ? and ; work as before.

    coreBeta

Files & safety

  • Delete safety net

    Deletes and overwrites keep the old files for 3 days, in a hidden folder at the root of the drive, so your folders stay clean. Ctrl+Z puts them back, also after a restart. Works on network shares too.

    coreBeta

  • Recently deleted

    A list in Ctrl+K, grouped by day. Enter restores a file and Delete removes it for good. Kept files clean up on their own.

    coreBeta

  • Safety net settings

    Settings › Safety net sets how long files are kept (1 to 7 days), the space per drive and the free-space floor.

    coreBeta

  • Multi-select

    Mark files the Total Commander way, with keys or the mouse, then act on all of them at once.

    coreAlpha

  • Drag and drop

    Drag marked files between panes, folders, tabs, path crumbs and drives, and to and from Windows Explorer. Drop with the right button to choose copy, move or shortcut.

    coreAlpha

  • Multi-rename (Ctrl+M)

    Rename many files with a live preview. Edit, paste or load names, sort, and number with counters. Undo is safe, even after a crash. Works on FAT and exFAT drives.

    coreAlpha

  • File operations

    Copy and move in the background with a progress card, pause and resume, and automatic copy mode. Files in use are reported.

    coreAlpha

  • Open a terminal here

    Opens Windows Terminal, PowerShell or cmd in the current folder, with templates. A folder name can never run as a command.

    moduleBeta

  • Safer storage

    Session and settings are stored more safely. The settings file can be edited by hand.

    coreAlpha

Layout

  • Tiled panes with layouts

    Up to four panes, tiled like a window manager. Ctrl+L picks one of five layouts or your own. V and S split, X closes, Shift+arrows swap and Ctrl+arrows resize.

    coreBeta

  • Pane controls

    Drag a divider and a guide line shows where it lands. Shift+drag a pane header to swap panes. Ctrl+Shift+1–4 jumps to a pane, and the F5/F6 target is outlined.

    coreBeta

  • Workspaces

    Alt+1 to Alt+9 switch between named workspaces, each with its own layout, tabs and target pane. A tray shows them as cards. They save themselves while you work.

    coreBeta

  • Narrow windows

    In a narrow window one pane shows, and a strip of buttons switches between the others.

    coreBeta

  • Clone a tab

    Ctrl+Shift+Up opens the current folder as a new tab in the other pane.

    coreBeta

  • Calm window

    Choose what the main window shows: the shortcut drawer, a compact F-key bar, the folder preview side sheet and the activity strip.

    coreAlpha

  • Close tabs with X

    Every tab has an X, and middle-click closes it. Closing the last tab closes the pane. Clicking a pane header makes it active.

    coreBeta

  • 2×2 grid rows

    In a 2×2 grid each row has its own divider. Ctrl+Alt+0 evens them all.

    coreBeta

Viewers

  • F3 viewer and F4 editor

    Opens any file: text as text, anything else in hex. Search with a live count, marks and an encoding picker.

    moduleAlpha

  • Markdown, JSON, YAML and XML

    Markdown renders in F3, with a live preview while you edit. JSON, YAML and XML open as a tree.

    moduleAlpha

  • PDF, images, fonts and archives

    View PDFs, pictures, fonts and archive contents in F3, and step through the files of a folder.

    moduleAlpha

  • Rich ELF and MAP views

    ELF symbols and TASKING linker maps as rich tables, with memory models, companion file discovery and module prefixes.

    moduleAlpha

  • Memory and trace files

    Intel HEX and S-record memory views, and CAN traces in Vector ASC, TRC and BLF formats.

    moduleAlpha

  • DBC and A2L outline

    An outline of senders, messages and signals in F3, and tables in the rich view.

    moduleBeta

  • Follow (Alt+F)

    Watch a growing log. New lines show even while another program keeps the file open.

    moduleBeta

  • Find in every view

    Ctrl+F searches text, hex, tables, trees and Markdown, shows "3 of 17" and highlights every match.

    moduleBeta

Look & feel

  • Colour themes

    Six built-in themes, each in light and dark: Open sea (the default), Red bill, Black cap, Fine mesh, Grain, and Ink and amber. Applies at once.

    packageAlpha

  • Right-click menu

    The real Windows shell menu in Navo’s style, with a filter at the top. Submenus open in place and Shift adds the extended items.

    coreAlpha

  • New name and splash

    Navo has a new name, the n_ icon and a quiet start-up splash that only shows when start-up is slow. Settings, tabs and history move over from Ferrite.

    coreAlpha

  • Modern look

    Space Grotesk for the brand, Inter for the interface and JetBrains Mono for paths and viewers.

    coreBeta

  • Settings (Ctrl+,)

    A side sheet that marks every setting as Default or Changed, with a Find a setting box.

    coreAlpha

  • Diagnostics

    A log with private data removed, crash reports with file and line, cache sizes, and a report you can save by hand.

    coreAlpha

  • Window and display

    The window opens where it was, stays sharp at any display scale, and only one Navo runs at a time.

    coreAlpha

  • User guide (Shift+F1)

    A short guide for new users opens in the viewer, with search and working contents links. F1 shows every shortcut, and Settings has a Help section.

    coreBeta

  • Colours follow the theme

    Shadows, overlays, the size map and the compare colours all come from the theme, so every theme looks whole.

    coreBeta

  • Leaner release build

    Release builds carry no performance recording or input traces. Those live in a separate tester build.

    infraBeta

Speed

  • Navo in the tray

    Optional: closing hides Navo and keeps your tabs; Win+Alt+N (changeable in Settings) brings it back. Starting navo.exe again shows the hidden window.

    corev1.0

  • Smooth in big folders

    Sorting and filtering run off the window thread, totals are counted once per listing, and selecting files no longer copies the list.

    corev1.0

  • Measured on your laptop

    Start Navo with --trace to record how long every key press takes to reach the screen, so each change is proven with numbers.

    corev1.0

  • Right-click menu only when asked

    The Windows menu and its extensions load only when you open it, not while you move the cursor.

    corev1.0

  • Fewer disk writes

    History, cache and logs are written in small batches. Your files and the safety net keep full protection.

    corev1.0

  • Drives update on their own

    The drive list refreshes when Windows reports a USB stick, disc or network share, and when you come back to Navo. No more checking every 2 seconds.

    corev1.0

  • Quiet when idle

    Navo no longer wakes up five times a second to check for a second copy of itself. It waits for events instead.

    corev1.0

  • Never freezes on slow work

    F4, opening a terminal, opening files, copy, cut, paste and Ctrl+Z run in the background. A late answer never undoes the wrong thing or replaces a newer dialog.

    corev1.0

  • Faster start

    The database opens once instead of four times. Routine clean-up waits a minute, urgent clean-up still runs at once, and code fonts and colours load when first needed.

    corev1.0

  • Lighter redraws

    Hovering a tab, scrolling or an animation redraws only that pane, not the whole window.

    corev1.0

  • PDFs ready sooner

    The PDF engine starts in the background a few seconds after Navo opens, so the first PDF opens without a wait.

    modulev1.0

  • Stricter code checks

    A stricter set of code checks, crate by crate, that also removes needless copies of data.

    infrav1.0

Next

Coming up, in order.

  • Next phase

    Speed

    Blazing-fast start, input, scrolling, big folders and low memory. The goal on a locked-down Windows laptop: Navo back from the tray in 50 ms, a warm start under 0.25 s, every key on screen within one frame, and under 80 MB.

    corev1.0

Speed phase, in order

  • Lighter memory

    Try the mimalloc memory allocator and keep it only if start-up, memory and folder listing get better on a Windows laptop.

    corev1.0

  • Speed checks that fail the build

    Instruction-count benchmarks (gungraun) and Tracy profiling, so a slowdown is caught before it ships.

    infrav1.0

Finishing the beta

  • Clipboard history and notes

    Keep what you copied (text, images and file lists), plus notes, in a Ctrl+K-style palette. Skips passwords that password managers mark as private. Opens from Win+Alt+N or the tray. Uses arboard and clipboard-win.

    moduleBeta

  • Collections

    Saved searches, snapshots and hand-picked files, kept as virtual folders you can open and work in.

    coreBeta

  • Background work that never waits

    Folder sizes stop when you leave the folder. Size on disk, and hard links counted once.

    coreBeta

  • Accessibility basics

    Narrator reads lists, dialogs and Ctrl+K. Focus is visible everywhere. Reduced motion, contrast themes and UI scale.

    coreBeta

  • Command library

    Your own commands in sections: Enter copies, {VAR} comes from a profile and <name> fields are asked for on copy. {MOD} can follow the folder you are in. Reads an existing commands.json, so a team can share one list. Commands also show in Ctrl+K. Variables use minijinja.

    moduleBeta

  • Smarter search

    Ctrl+K results stay in place while the index updates, with a line that shows how fresh it is. Plain words become filters (“pdf from last week over 5 MB”). Content search follows .gitignore and understands -exclude and “exact phrase”. Uses grep-searcher and grep-regex.

    coreBeta

  • Matching lines in results

    The matching lines show under each file in the results tab, so you see why it matched without opening it.

    coreBeta

  • Keys your way

    Key combinations parsed and shown the same way everywhere (crokey), a conflict view and reset per key.

    coreBeta

Replaces Total Commander

  • Inspector and preview

    A side column with preview, properties and thumbnails from Windows itself (video, HEIC, Office, RAW), resized with fast_image_resize. File details, owner and hashes are already there.

    corev1.0

  • Archives as folders

    Open zip, 7z, tar, tar.gz, tar.xz, tar.zst and tar.bz2 archives like folders (zstd, liblzma, bzip2). No RAR: 7-Zip covers it.

    corev1.0

  • Default file manager

    Optional: Win+E opens Navo.

    corev1.0

  • Modules and notifications

    Turn modules on and off while running, with a safe mode. The settings window builds itself from each module. Notifications for long operations.

    corev1.0

  • Faster copy

    Copy through Windows CopyFile2 for progress and cancel from the system, and instant copies on drives that can clone files (ReFS, Dev Drive) with reflink-copy. Junctions are created and shown correctly.

    corev1.0
